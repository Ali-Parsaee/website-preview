Learning on a real robot

How does the timing of learning and action matter?

Preprint · arXiv 2025 · presented at RISE

Synchronous vs Asynchronous Reinforcement Learning in a Real World Robot

Ali Parsaee, Fahim Shahriar, C. He, R. Tan
All authors contributed equally

Read the paper (arXiv) ↗

A robot that stops to learn falls behind a changing world. Learning in parallel with acting gave faster learning and more reward, even with fewer learning updates.

Simulated reaching task. The findings quoted are from the robot experiments.

The problem

Reinforcement learning agents improve through expensive gradient updates. In simulation the world waits for them; a physical robot’s environment does not.

What we did

We compared synchronous and asynchronous learning on a Franka Emika Panda arm in a visual reaching task: 25 runs for each of four settings, 100 runs and about 200 hours of robot time.

What we found

  • Asynchronous agents learned faster and earned significantly more reward.
  • Faster response time beat a larger number of gradient updates: the asynchronous high-resolution agent made fewer updates and still did better.
Go deeper

Because rewards cannot be observed continuously, reward was set in proportion to the length of the action cycle, so agents that act more often are not unfairly favoured.
