Hierarchical memory for language agents

How much detail is worth keeping as information ages?

MemAgents workshop · ICLR 2026

Toward a Theory of Hierarchical Memory for Language Agents

Yashar Talebirad, Ali Parsaee, Csongor Y. Szepesvari, Amirhossein Nadiri, Osmar Zaiane
Joint first author

Read the paper (arXiv) ↗

Every hierarchical memory system can be described with three operators: extract atomic units, coarsen them into groups with representatives, and traverse the hierarchy under a token budget.

Illustration of the three operators on a small hierarchy.

The problem

Long-context and agentic systems keep adding hierarchical memory to get around context limits. Each system is presented as its own design, with no shared language for comparing the choices they make.

What we did

We proposed a unifying theory. Extraction (α) maps raw data to atomic units. Coarsening (C) groups units and gives each group a representative. Traversal (τ) chooses which units enter the context for a query and a budget.

What we found

  • A “self-sufficiency spectrum” for representatives: summaries that can stand in for their group, versus keys that only point to it.
  • Where a system sits on that spectrum constrains which traversal strategies work: coarsening and traversal must be chosen together.
  • The decomposition describes eleven existing systems, spanning document hierarchies, conversational memory and agent execution traces.
Go deeper

Complex agentic tasks involve three coupled hierarchies: stored knowledge, the agent’s own traces, and the task’s decomposition. How they should align is an open question the paper raises.
