From Signals to Structure

How does memory shape the emergence of language?

ALIFE 2026

From Signals to Structure: How Memory Architecture Drives Language Emergence in LLM Agents

Yashar Talebirad, Eden Redman, Ali Parsaee, Osmar R. Zaïane

Read the paper ↗arXiv ↗

Whether two agents invent a stable shared language depends more on how they remember than on how much they can say.

A toy version of the game with simple learning agents, not LLMs. The accuracy figures quoted are the paper’s.

The problem

In a Lewis signalling game, a sender sees a target among several objects and sends a signal; a receiver must pick the target from the signal alone. With no agreed meanings, any consistent success means the pair has invented a small language.

What we did

We compared five memory architectures for LLM agents across channel sizes, from stateless agents with a rolling context window to agents with a persistent private notebook.

What we found

  • Memory architecture mattered more than channel capacity.
  • Agents with a persistent notebook coordinated most reliably: 0.867 ± 0.023 at a capacity of 25 signals.
  • Stateless agents peaked at moderate capacity, then degraded as the vocabulary outgrew their window.
  • Capacity equal to the number of objects (8), which an information-bottleneck argument predicts as optimal, was instead a fragile point.
Go deeper

Notebooks have their own failure mode: agents sometimes revise an established mapping in the middle of a game, which breaks the convention the partner relies on.
