Memory Is Communication

What changes when information is remembered or exchanged?

ALIFE 2026 · late-breaking abstract

Memory Is Communication: The Frontier Between Remembering and Signaling

Yashar Talebirad, Eden Redman, Ali Parsaee, Osmar R. Zaïane

Read the abstract (arXiv) ↗

An agent can get the information for a decision from its own past or from a peer. Under limits on both, the two trade off along a frontier.

Exact message requirements for a simple process where the target repeats with some probability.

The problem

Cooperative agents act from partial views with limited memory and limited bandwidth. Retained history can carry what a peer would otherwise have to say, and a message can supply what memory lacks.

What we did

We defined the remembering–signalling frontier: the efficient boundary of memory and message rates that reach a given performance. We hypothesize that an agent needs less communication when its history reduces task loss more.

What we found

  • In preliminary referential games, targets that repeated came with shorter successful messages.
  • Predictability from a hidden cyclic rule did not shorten messages.
  • This is a hypothesis-stage abstract; the paper outlines experiments to estimate the frontier.
Go deeper

The idea connects to rate-distortion theory and to Wyner–Ziv coding, where information already at the receiver lowers the bits needed to reach an error target.
